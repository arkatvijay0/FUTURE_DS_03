# Processed Dataset

This folder contains the cleaned and analysis-ready version of the Bank Marketing dataset.

## File

`bank_marketing_cleaned.csv`

## Description

The processed dataset was prepared for exploratory analysis and Power BI visualization.

It contains the original campaign and customer attributes along with derived analytical features used in the project.

## Key Preparation Steps

- Data type verification
- Duplicate checking
- Categorical value inspection
- Conversion variable preparation
- Age-group creation
- Campaign contact grouping
- Previous-contact indicator
- Month-number creation

## Usage

This file is used by the Jupyter Notebook and Power BI dashboard for analysis and visualization.
