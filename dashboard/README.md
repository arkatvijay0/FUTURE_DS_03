# Power BI Dashboard

This folder contains the interactive Power BI dashboard created for the Bank Marketing Campaign & Conversion Performance Analysis.

## File

`Bank_Marketing_Campaign_Analysis.pbix`

## Dashboard Pages

### Page 1 – Executive Overview

Provides an overall summary of campaign performance, conversion KPIs, funnel performance, contact-channel performance, and monthly trends.

### Page 2 – Channel & Campaign Performance

Analyzes contact-channel performance, campaign outcomes, and previous campaign outcomes.

### Page 3 – Customer Segments & Conversion Trends

Analyzes conversion performance across age, education, occupation, marital status, housing, and loan segments.

## Tool

Microsoft Power BI
